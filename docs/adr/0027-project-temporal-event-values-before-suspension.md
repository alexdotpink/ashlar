# Project temporal event values before suspension

Temporal event APIs will expose receiver-style `await`, `capture`, and `stream` operations. Their selectors run synchronously in the native callback and return ashlar-owned values, so raw Paper objects do not enter a suspended query or Flow. `skip()` ignores an unrelated event, while `retry {}` keeps a capture active and schedules feedback outside the callback. Await and stream default to `MONITOR`; capture defaults to `HIGHEST` and ignores earlier cancellation. Deadlines are optional because coroutine cancellation owns indefinite waits. Matching Folia callbacks run concurrently, and an atomic first acceptance wins without cancelling a losing callback. Streams require explicit bounded capacity and overflow because server event dispatch cannot wait for collectors.
