# Embed and own one kernel per plug-in

Each framework plug-in will bundle its own kernel and selected modules in a self-contained JAR. Embedded packages keep their original names; Paper and Folia fixtures containing two plug-ins with different framework versions will verify classloader isolation. `FrameworkPlugin` owns final Paper lifecycle callbacks, one supervised coroutine scope with child scopes matching the component tree, statically declared plug-in components, and deterministic resource cleanup. Disable cancels tasks, drains them for two seconds by default, runs the plug-in's final-action hook, stops the component tree, then closes remaining owned resources. Plug-ins may configure a longer drain. Hot reload is unsupported. This avoids a separately installed framework plug-in, package rewriting, shared-runtime version conflicts, and lifecycle ordering that depends on authors calling `super`.
