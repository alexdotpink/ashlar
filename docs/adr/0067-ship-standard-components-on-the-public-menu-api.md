# Ship standard components on the public menu API

The menu module will include polished standard components for recurring interaction patterns, including pagination, scrolling, tabs, selection, confirmation, toggles, number stepping, framing controls, and asynchronous content states. They will be ordinary composable Kotlin functions built only on the public menu API, so plug-ins can wrap, replace, and learn from them without privileged runtime behavior. Textual search and prompts will compose with the input module.
