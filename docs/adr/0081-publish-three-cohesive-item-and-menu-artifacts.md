# Publish three cohesive item and menu artifacts

The public dependency set will consist of `framework-items`, `framework-menus`, and `framework-menus-test`, with menus depending transitively on items. Runtime engines and native adapters may use private internal projects without becoming consumer choices. Standard command, input, and other integrations activate only when their framework capabilities are installed, avoiding both a monolith and a matrix of per-host or per-feature artifacts.
