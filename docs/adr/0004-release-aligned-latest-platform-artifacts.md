# Release aligned artifacts for the latest platform

The framework will publish kernel, build tooling, BOM, test kit, incubator, and official modules from one Gradle multi-project repository under a unified SemVer release. Builds pin exact Kotlin, Java, Paper, and Folia baselines; automation proposes updates, and every change runs real Paper and Folia integration tests plus public API validation. Public concepts require KDoc and compile-checked samples exercised by fixture plug-ins. The consumer Gradle plug-in supplies managed defaults, generates standard `plugin.yml`, and requires authors to acknowledge Folia support explicitly. Official artifacts target Maven Central under Apache-2.0. Version 1 supports only the latest stable server line, while a private platform adapter may use NMS as a last resort and leaves room for future version-specific adapters.
