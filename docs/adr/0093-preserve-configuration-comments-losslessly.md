# Preserve configuration comments losslessly

Human-authored comments are part of an Ashlar configuration document and must survive explicit updates, migrations, backup restoration, and watched reloads. YAML, TOML, and JSONC formats retain comment tokens. Strict JSON remains comment-free. Comments from removed keys stay at their parent, and KDoc seeds comments only when keys are first created. Typed migrations do not edit operator comments. This requires lossless format documents and patching rather than decode-and-regenerate writes, but avoids destroying the operational knowledge commonly stored beside Minecraft settings.
