# Preserve configuration comments losslessly

Human-authored comments are part of an Ashlar configuration document and must survive explicit updates, migrations, backup restoration, and watched reloads. YAML, TOML, and JSONC formats will retain comment tokens; strict JSON remains comment-free, comments from removed keys stay at their parent unless a migration explicitly moves them, and KDoc seeds comments only when keys are first created. This requires lossless format documents and patching rather than decode-and-regenerate writes, but avoids destroying the operational knowledge commonly stored beside Minecraft settings.
