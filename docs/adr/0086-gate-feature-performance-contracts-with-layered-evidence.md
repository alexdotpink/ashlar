# Gate feature performance contracts with layered evidence

Every public framework capability will own explicit, versioned `small`, `typical`, and `stress` workload profiles rather than one benchmark per trivial operation. Contracts will pair matched controls that isolate framework overhead with end-to-end journeys where both are meaningful, and will cover KSP, Gradle, compilation, generated output, and artifact size as well as runtime behavior. Pull requests will compare their branch with current `main` on the same worker, using JVM microbenchmarks for isolated costs, server workloads for Paper/Folia behavior, and connected-client scenarios only for claims that depend on the client protocol; pure Kotlin work runs once, while ownership and native-adapter scenarios run on both Paper and Folia.
