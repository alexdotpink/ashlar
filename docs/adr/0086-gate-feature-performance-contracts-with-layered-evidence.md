# Gate feature performance contracts with layered evidence

Every public framework capability will own representative cold, warm, normal-load, and stress performance scenarios rather than one benchmark per trivial operation. Pull requests will compare their branch with current `main` on the same worker, using JVM microbenchmarks for isolated costs, server workloads for Paper/Folia behavior, and connected-client scenarios only for claims that depend on the client protocol; pure Kotlin work runs once, while ownership and native-adapter scenarios run on both Paper and Folia.
