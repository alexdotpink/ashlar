# Gate feature performance contracts with layered evidence

Every public framework capability will own explicit, versioned `small`, `typical`, and `stress` workload profiles rather than one benchmark per trivial operation. Contracts will pair matched direct Kotlin, Paper, Folia, or toolchain controls that isolate framework overhead with end-to-end journeys where both are meaningful; other-framework comparisons are separate non-blocking research. Framework extension seams use fixed fast, delayed, and failing fixtures, while concrete external adapters receive contracts only when the repository ships them. Contracts cover KSP, Gradle, compilation, generated output, and artifact size as well as runtime behavior. Pull requests compare their branch with current `main` on the same worker, using JVM microbenchmarks for isolated costs, deterministic server-side actors for scalable Paper/Folia load, and smaller connected-client scenarios only for claims that depend on the client protocol; pure Kotlin work runs once, while ownership and native-adapter scenarios run on both Paper and Folia.
